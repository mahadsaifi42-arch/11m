# 11 Months — Our Story

A premium romantic interactive website built with pure HTML, CSS, and JavaScript.
No frameworks. No dependencies. No internet required after loading Google Fonts.

---

## How to Open

Simply open `index.html` in any modern browser.
Chrome, Firefox, Edge, or Safari all work perfectly.

---

## Features

- Animated loading screen with star canvas
- Cinematic hero section with parallax stars, floating hearts, and particles
- Chapter-style story with typing text effect
- Interactive memory gallery with hover/tap reveals
- 4 mini games: Catch Hearts, Choose Our Future, Relationship Quiz, Open When
- Envelope with letter animation and full typing reveal
- Emotional cinematic ending with shooting stars and slow typing
- Ambient background music via Web Audio API (no files needed)
- Cursor glow effect (desktop)
- 5 hidden easter eggs throughout the site
- Scroll reveal animations on all sections
- Ripple micro-interactions on buttons
- Fully responsive on mobile
- Smooth parallax scrolling on hero

---

## Customisation

- Edit chapter text inside `index.html` within each `.chapter-text` element's `data-text` attribute
- Edit the ending paragraph in the `#ending-paragraph` element's `data-text`
- Edit the letter inside the `#letter-content .letter-body` element's `data-text`
- Edit quiz questions and answers in `QUIZ_DATA` array in `script.js`
- Edit Open When messages in `OPEN_WHEN` object in `script.js`
- Add your own photos by placing them in `assets/` and referencing them in the gallery section
